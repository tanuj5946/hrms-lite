# HRMS Lite

A lightweight Human Resource Management System.

## Features
- Add / View / Delete Employees
- Mark Attendance
- View Attendance per Employee

## Tech Stack
- Frontend: React (Vite)
- Backend: FastAPI
- Database: SQLite

## Run Backend
cd backend  
venv\Scripts\activate  
python -m uvicorn app.main:app --reload  

## Run Frontend
cd frontend/hrms-frontend  
npm install  
npm run dev
